## 安全架构

```
┌───────────────────────────────────────────────────────────────────┐
│                          安全防护层                                 │
│                                                                     │
│  ┌────────────────┐  ┌────────────────┐  ┌────────────────┐       │
│  │  SQL Injection │  │  XSS Attack    │  │  CSRF Attack   │       │
│  │   Protection   │  │   Protection   │  │   Protection   │       │
│  └────────┬───────┘  └────────┬───────┘  └────────┬───────┘       │
│           │                   │                    │                │
│  ┌────────▼───────────────────▼────────────────────▼───────┐       │
│  │                                                           │       │
│  │  1. PreparedStatement (SQL注入防护)                      │       │
│  │     String sql = "SELECT * FROM users WHERE id = ?";     │       │
│  │     stmt.setInt(1, userId);                              │       │
│  │                                                           │       │
│  │  2. HTML Escaping (XSS防护)                              │       │
│  │     input.replace("<", "&lt;").replace(">", "&gt;")      │       │
│  │                                                           │       │
│  │  3. CSRF Token Validation (CSRF防护)                     │       │
│  │     if (!token.equals(sessionToken)) reject();           │       │
│  │                                                           │       │
│  │  4. Password Encryption (密码加密)                        │       │
│  │     SHA-256 Hash                                          │       │
│  │                                                           │       │
│  │  5. Session Management (会话管理)                         │       │
│  │     Timeout: 30 minutes                                   │       │
│  │                                                           │       │
│  │  6. File Upload Security (文件上传安全)                   │       │
│  │     Size limit: 10MB, Type check: image/*                │       │
│  │                                                           │       │
│  └───────────────────────────────────────────────────────────┘       │
│                                                                     │
└───────────────────────────────────────────────────────────────────┘
```

## 数据流向图

```
┌─────────────┐
│   Browser   │
└──────┬──────┘
       │
       │ 1. HTTP Request
       ▼
┌─────────────┐
│   Filters   │ ←── Auth Check, CSRF Validation
└──────┬──────┘
       │
       │ 2. Filtered Request
       ▼
┌─────────────┐
│  Servlets   │ ←── Session Management
└──────┬──────┘
       │
       │ 3. Business Logic Call
       ▼
┌─────────────┐
│   Service   │ ←── Security (Sanitization, Validation)
└──────┬──────┘
       │
       │ 4. Data Access
       ▼
┌─────────────┐
│     DAO     │ ←── PreparedStatement
└──────┬──────┘
       │
       │ 5. SQL Query
       ▼
┌─────────────┐
│   Database  │
└──────┬──────┘
       │
       │ 6. Result Set
       │
       ▼
   (Return path follows same layers in reverse)
```
