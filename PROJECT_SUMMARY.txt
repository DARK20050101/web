📋 项目概述 (Project Overview)

🔒 安全特性 (Security Features)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ SQL 注入防护
   • 所有查询使用 PreparedStatement
   • 参数化查询，避免 SQL 拼接

✅ XSS 防护
   • HtmlUtil.escapeHtml() 统一转义
   • 所有用户输入输出时转义
   • Content Security Policy (CSP) 头

✅ CSRF 防护
   • 每个 session 生成唯一 token
   • 非 GET 请求强制验证 token
   • SecureRandom 生成随机 token

✅ 文件上传安全
   • MIME 类型白名单验证
   • ImageIO 内容验证
   • 文件大小限制
   • UUID 文件命名
   • 路径穿越防护
   • nosniff 头保护

✅ 会话安全
   • HTTP-only Cookie
   • 可配置超时时间
   • 安全退出机制

✅ 访问控制
   • 基于 Filter 的认证
   • 管理员权限检查
   • 受保护路径控制

🚀 部署步骤 (Deployment Steps)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 执行数据库脚本
   mysql -u root -p < sql/schema.sql
   mysql -u root -p < sql/alter_001_add_image_path.sql

2. 配置数据库连接
   编辑 src/main/java/com/messageboard/util/DBUtil.java

3. 构建项目
   mvn clean package

4. 部署到 Tomcat
   cp target/message-board.war $TOMCAT_HOME/webapps/

5. 启动服务器
   $TOMCAT_HOME/bin/catalina.sh start

6. 访问应用
   http://localhost:8080/message-board/
